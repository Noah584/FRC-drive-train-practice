# FRCDesign.org Swerve Chassis Drivetrain CAD Practice 

Design from [FRCDesign.org](https://frcdesign.org/)

An interactive 3D CAD of an FRC (FIRST Robotics Competition) chassis featuring MK4N swerve modules, custom-cut structural aluminum extrusion tubing, and standardized fastening layouts.

## Interactive 3D Model
* View/Download STL: You can view the fully assembled chassis directly in your browser via the `FRC drive train practice.stl` file above, or download and import to CAD software.
* **Open in Onshape:** Check out the full parametric tree, mates, and more subassemblies in [Onshape (View-Only)](https://cad.onshape.com/documents/f6af3492d41d41f5d94411cd/w/a67bdf7e734d48a2795a60d7/e/d4fe4770bb0f6c9d8ab6f7c6).

## Features
* **Chassis Layout:** Built using standard FRC aluminum profile tubing (`1"x1"` and `2"x1"` structural framing).
* **Swerve Drive Integration:** 4x `Simplified MK4N` swerve modules positioned at the corners for holonomic drive simulation and packaging studies.
* **Fastening & Gusseting:** Assembled using standard FRC hardware patterns, including socket head cap screws, structural rivets, and custom-spaced mounting plates.
